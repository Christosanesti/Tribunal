# BMAD Output - Tribunal

This directory contains all BMAD (Build-Measure-Adjust-Document) planning artifacts for the Tribunal project.

## Contents

- `planning-artifacts/` - Product brief, sprint plans, user stories

## Structure

```
_bmad-output/
├── planning-artifacts/
│   ├── product-brief.md      # Full product brief
│   ├── user-stories.md       # User stories
│   ├── technical-spec.md     # Technical specifications
│   └── sprint-plan.md        # Sprint planning
└── [future]/
    ├── retrospectives/
    ├── metrics/
    └── decisions/
```

## BMAD Process

1. **Build**: What are we building? (Product brief, specs)
2. **Measure**: How do we measure success? (Metrics, KPIs)
3. **Adjust**: How do we iterate? (Retrospectives, adjustments)
4. **Document**: What do we document? (Decisions, learnings)

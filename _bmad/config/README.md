# BMAD Configuration

This directory contains BMAD (Build-Measure-Adjust-Document) configuration for the Tribunal project.

## Structure

- `config/`: BMAD configuration files
- `templates/`: Document templates for BMAD process
- `scripts/`: BMAD automation scripts

## Usage

BMAD is a structured product development methodology. This config defines:

1. **Build**: What to build (features, priorities)
2. **Measure**: How to measure success (metrics, KPIs)
3. **Adjust**: How to iterate based on feedback
4. **Document**: What to document and how

See `_bmad-output/planning-artifacts/` for generated artifacts.
